# Digital business cards

Each `<slug>.json` here becomes a scannable contact card at `https://stravitech.com/c/<slug>`.
Opening that URL on a phone downloads `<slug>.vcf` so the visitor can save the contact in one tap.

- **Add a person:** copy an existing file, rename it to the slug printed on their QR code (lowercase), edit the values.
- **Update a person:** edit their JSON, commit, push. Live in ~1–2 minutes; printed QR codes keep working.
- The `.vcf` and page are generated by `scripts/build-contacts.mjs` before every `npm run dev` / `npm run build`
  into `public/c/` (gitignored). Never edit those directly.
- The build fails with a clear message if a file is invalid, so a broken card never deploys.

Fields: `firstName`, `lastName`, `organization`, `title`, `phones` (`[{ type, number }]`, number like `+919764830503`),
`emails` (`[{ type, address }]`), `website`, `address` (`street`, `city`, `region`, `postalCode`, `country`), `note`.
Name plus at least one phone or email is required; everything else is optional.
