# Contact cards

Each `<slug>.json` here is one person's contact. It produces two things:

| Output | Where | What it does |
|---|---|---|
| **Printed QR code** | `contacts/qr/<slug>.svg` / `.png` (run `npm run contacts:qr`) | The QR holds the vCard itself, so any scanner or phone camera shows **Add contact** directly — no internet, no website. Use this on visiting cards. |
| **Shareable link** | `https://stravitech.com/c/<slug>.vcf` (built on every deploy) | Opens the contact file on the phone for saving. Use in WhatsApp, email signatures, LinkedIn. |

- **Add / update a person:** edit (or copy and rename) their JSON. Commit + push updates the link in ~1–2 minutes.
  A printed QR can't change after printing — run `npm run contacts:qr` and reprint when details change.
- **Printing:** send the `.svg` (vector, sharpest) to the printer. Print at least **2.5 cm wide**, black on white,
  and keep the white border around it.
- Outputs are generated by `scripts/build-contacts.mjs` and gitignored. Never edit them directly.
- The build fails with a clear message if a file is invalid, so a broken card never deploys.

Fields: `firstName`, `lastName`, `organization`, `title`, `phones` (`[{ type, number }]`, number like `+919764830503`),
`emails` (`[{ type, address }]`), `website`, `address` (`street`, `city`, `region`, `postalCode`, `country`), `note`.
Name plus at least one phone or email is required; everything else is optional.
